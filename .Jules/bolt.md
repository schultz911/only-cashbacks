## 2024-06-03 - [Memoize Derived Wallet Cards Data in React]
**Learning:** In `App.tsx`, the `CARD_DATA` array was being redundantly filtered on every render inside JSX loops (e.g., wallet display). This caused redundant O(N) filtering operations and frequent memory allocations. We must be careful not to change the signature of core logic functions like `getRecommendations` to preserve exact wallet state behavior and avoid breaking dependents.
**Action:** Use `useMemo` to pre-calculate and cache the `activeWalletCards` array in `App.tsx` and pass the memoized array to UI render loops. Leave the `getRecommendations` signature and internal lookups intact to preserve explicit wallet state and fallback logic.
